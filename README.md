# Loan Approval Prediction using Machine Learning

## 📌 Project Overview

This project predicts whether a loan application will be **Approved** or **Rejected** using machine learning classification algorithms.

It covers data preprocessing, exploratory data analysis (EDA), statistical analysis, feature selection, model training, hyperparameter tuning, model evaluation, explainability (permutation importance and SHAP), and model saving. The trained model can be used to score new loan applicants.

## ✨ Highlights

* Compared **Logistic Regression**, **Random Forest** and **Gradient Boosting** with 5-fold `GridSearchCV` (ROC-AUC).
* Final model: **Random Forest**, with **97.9% accuracy**, **0.983 F1** and **0.999 ROC-AUC** on 854 held-out applications.
* **CIBIL score dominates the decision**: removing it drops test ROC-AUC from 0.999 to 0.602.

---

## 🎯 Project Objective

Build a model that predicts loan approval from applicant and loan information, and identify which factors drive the decision.

Target variable `loan_status`: `1` = Approved, `0` = Rejected.

## 📊 Dataset

4,269 loan applications, with no missing values and no duplicates. 62% are approved.

Features used:

* `no_of_dependents`
* `income_annum`
* `loan_amount`
* `loan_term`
* `cibil_score`
* `residential_assets_value`
* `commercial_assets_value`
* `luxury_assets_value`
* `bank_asset_value`

Handled separately:

* `loan_id` is removed because it is only an identifier.
* `loan_status` is the target.
* `education` and `self_employed` were tested with a chi-square test. Neither was related to approval (p = 0.77 and 1.00), so both were dropped.

The CSV is not included in the repository. See [`data/README.md`](data/README.md).

## 🔄 Machine Learning Workflow

```text
Data Cleaning → EDA → Statistical Analysis → Feature Selection
→ Train/Test Split → GridSearchCV → Evaluation
→ Explainability (Permutation Importance, SHAP) → Model Saving
```

### Preprocessing

1. Strip extra spaces from column names and categorical values.
2. Encode categorical values as numbers.
3. Check missing values and duplicates.
4. Analyse class distribution.
5. Remove `loan_id`; drop features that fail the chi-square test.
6. Stratified 80/20 train/test split (`random_state=42`).

### Models and tuning

| Model | Tuned parameters |
|---|---|
| Logistic Regression (with `StandardScaler`, balanced classes) | `C` |
| Random Forest (balanced classes) | `n_estimators`, `max_depth`, `min_samples_leaf` |
| Gradient Boosting | `n_estimators`, `learning_rate`, `max_depth` |

`GridSearchCV` uses 5-fold cross-validation on the training set only, optimising ROC-AUC. The model with the highest cross-validation ROC-AUC is selected.

## 📈 Results

| Model | Accuracy | Precision | Recall | F1 | Test ROC-AUC |
|---|---|---|---|---|---|
| Logistic Regression | 0.9215 | 0.9531 | 0.9190 | 0.9358 | 0.9734 |
| **Random Forest** (selected) | 0.9789 | 0.9849 | 0.9812 | 0.9830 | 0.9988 |
| Gradient Boosting | 0.9836 | 0.9832 | 0.9906 | 0.9869 | 0.9976 |

Random Forest and Gradient Boosting are effectively tied on the test set.

## 📌 Prediction Example

```bash
python src/predict.py
```

Or from Python:

```python
import joblib
import pandas as pd

model = joblib.load("models/loan_model.pkl")

applicant = pd.DataFrame([{
    "no_of_dependents": 3,
    "income_annum": 8_300_000,
    "loan_amount": 31_400_000,
    "loan_term": 6,
    "cibil_score": 674,
    "residential_assets_value": 1_000_000,
    "commercial_assets_value": 1_600_000,
    "luxury_assets_value": 17_200_000,
    "bank_asset_value": 6_100_000,
}])

print(model.predict(applicant))          # 1 = Approved, 0 = Rejected
print(model.predict_proba(applicant))    # [P(rejected), P(approved)]
```

## ⚠️ Limitations and Disclaimer

* The near-perfect scores and heavy reliance on one feature suggest the data may be clean or synthetic. Real lending data is noisier, so these numbers may not carry over.
* A single train/test split was used, with no external validation.
* This project is for **educational and portfolio purposes**. A real loan system would need fairness checks, regulatory compliance, explainability, data-quality controls and human oversight.
